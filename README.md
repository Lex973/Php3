# Практическая работа №5 по PHP

Стрелочные и анонимные функции.

## Запуск

PHP 7.4 или новее. Каждый файл запускается отдельно: `php task1.php`, `php task2.php`, `php task3.php`, `php task4.php`, `php task5.php`.

## Контрольные вопросы

1. **Чем fn отличается от function?** Стрелочная функция содержит одно выражение, автоматически возвращает его результат и захватывает внешние переменные по значению. Обычная анонимная функция может содержать несколько инструкций, требует return для возврата результата и захватывает локальные внешние переменные через use.
2. **Как fn захватывает переменные?** Автоматически по значению в момент создания функции. Поэтому последующее присваивание нового значения внешней переменной не изменяет захваченное значение.
3. **Можно ли записать несколько инструкций в fn?** Нет, тело состоит из одного выражения. Для сложной логики можно использовать обычную анонимную функцию или вызвать отдельную функцию из fn.
4. **Что возвращают array_map, array_filter и array_reduce?** array_map возвращает массив результатов преобразования элементов; обработчик получает элемент (или элементы нескольких массивов). array_filter возвращает отобранные элементы с сохранением ключей; обработчик проверяет условие. array_reduce сворачивает массив в одно значение; обработчик получает накопленный результат и текущий элемент.
5. **Как работает оператор <=>?** Возвращает -1, 0 или 1, если левый операнд меньше, равен или больше правого. Это соответствует требованиям функции сравнения в usort. Для сортировки по убыванию операнды меняют местами.
6. **Что выведет `$f = fn($x) => fn($y) => $x * $y; echo $f(2)(5);`?** Выведет 10. Первый вызов возвращает функцию, захватившую x = 2. Второй вызов передаёт y = 5, и функция возвращает произведение.
